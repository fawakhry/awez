# عاوز — النسخة التجريبية v0.1

حزمة بداية فعلية لتجربة مشروع **عاوز** في بنها.

## المحتويات

- `android/`: مشروع Android Native بـ Kotlin وJetpack Compose.
- `prototype/index.html`: نموذج تفاعلي سريع يفتح في المتصفح.
- `backend/`: API أولي بـ FastAPI للبحث والطلبات.

## الوظائف الموجودة

- بحث كتابي وصوتي بالعربية.
- نتائج أنشطة مرتبة تجريبيًا حسب القرب.
- صفحة نشاط ومنتجات.
- سلة متعددة المنتجات وفاتورة بالجنيه المصري.
- جولة 360 تعمل على الموبايل دون نظارة VR.
- نقاط تفاعلية داخل الجولة تضيف المنتجات للسلة.
- بيانات تجريبية لبنها.

## تشغيل تطبيق أندرويد

1. افتح مجلد `android` في Android Studio حديث.
2. نفّذ Gradle Sync.
3. شغّل التطبيق على هاتف أو Emulator بنظام Android 8 فأحدث.
4. وافق على إذن الميكروفون عند استخدام البحث الصوتي.

الجولة 360 تستخدم صورة تجريبية من الإنترنت. في الإنتاج، يرفع صاحب النشاط صور 360 الخاصة به، ويحدد نقاط المنتجات من لوحة التحكم.

## تشغيل الـ Backend

```bash
cd backend
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# macOS / Linux
source .venv/bin/activate
pip install -r requirements.txt
fastapi dev main.py
```

توثيق الـ API يظهر في: `http://127.0.0.1:8000/docs`

## ما يحتاج مرحلة الإنتاج

- حسابات العملاء والتجار والصلاحيات.
- لوحة تحكم التاجر.
- PostgreSQL وPostGIS للمواقع والمسافات.
- خرائط فعلية وتتبع عنوان العميل.
- الدفع وشركات التوصيل.
- المخزون اللحظي.
- رفع ومعالجة صور 360.
- نموذج ذكاء اصطناعي مفتوح المصدر وRAG على بيانات المنصة.
- الحماية والمراقبة والنسخ الاحتياطي.

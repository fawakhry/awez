# رابط تجاوز التنقل

## الأساس

توصي WCAG 2.4.1 بتوفير وسيلة لتجاوز الكتل المتكررة والوصول مباشرة إلى المحتوى الرئيسي، وتعرض تقنية W3C G1 رابطًا في بداية الصفحة ينتقل إلى منطقة المحتوى الأساسية.

المصادر:
- https://www.w3.org/WAI/WCAG21/Understanding/bypass-blocks
- https://www.w3.org/WAI/WCAG21/Techniques/general/G1

## التنفيذ

- رابط عربي يصبح ظاهرًا عند تركيز لوحة المفاتيح.
- الهدف هو عنصر `main`، مع نقل التركيز إليه عند التفعيل.
- التنفيذ idempotent ولا يضيف الرابط أو التنسيق أكثر من مرة.
- لا توجد مكتبات أو اتصالات خارجية جديدة.

## التحقق

```bash
node --check prototype/skip-link.js
node tests/skip-link.test.cjs
```
